# Todo List Repo

A simple repository containing a static HTML todo list application.

## Files

- `todo.html` — A standalone HTML todo list you can open in a browser.
- `.gitattributes` — Git attributes configuration for the repository.

## Usage

1. Open `todo.html` in your web browser.
2. Enter a task in the input field.
3. Click **Add** to create the task.
4. Mark tasks as complete with the **Done/Undo** button.
5. Remove tasks with the **Delete** button.

## Notes

- This is a static client-side page and does not require a server.
- Tasks are stored only in memory while the page is open.
